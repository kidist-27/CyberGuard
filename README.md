# CyberGuard 🛡️

**Learn. Recognize. Protect.**

CyberGuard is a simple Java console application that introduces basic cybersecurity awareness through security tips, a short quiz, and a basic password-length demonstration.

## Features

- **Security Tips:** Learn simple ways to protect your accounts.
- **Security Quiz:** Answer a question about password safety.
- **Password Check:** Try a fictional password and receive a basic length reminder.
- **Input Handling:** Invalid menu input will not crash the program.

## Requirements

- Java JDK 8 or later
- A terminal or Java-compatible coding app

## How to Run

1. Save the source file as `CyberGuard.java`.
2. Open a terminal in the folder containing the file.
3. Compile the program:

   ```bash
   javac CyberGuard.java
   ```

4. Run it:

   ```bash
   java CyberGuard
   ```

## Menu

```text
=== CYBERGUARD ===
1. Security Tips
2. Security Quiz
3. Password Check
4. Exit
```

## Important Security Note

CyberGuard is an educational demo, not a real security scanner or reliable password-strength checker. The password feature checks length only. Use fictional test passwords and never enter or store real passwords in this application.
